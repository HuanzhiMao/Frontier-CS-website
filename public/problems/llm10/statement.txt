TREE DISTANCE QUERY
===================

Time Limit: 2 seconds
Memory Limit: 512 MB

INTERACTIVE PROBLEM

PROBLEM DESCRIPTION
-------------------
Little Cyan Fish has a weighted tree of n vertices generated in the following way:
  1. First, generate a random labeled tree: uniformly randomly select from all n^(n-2) possible labeled trees
  2. Then, independently assign random integer edge weights in the range [1, K] to each edge, where K is a hidden parameter

You cannot directly observe the structure of the tree or the edge weights, but Little Cyan Fish grants you a superpower: querying!

Each time, you can query the distance between two vertices. Specifically, you can choose two vertices u, v (1 ≤ u, v ≤ n, u ≠ v), and we will tell you the distance between these two vertices (i.e., the sum of the edge weights on the simple path connecting these two vertices).

Your goal is to determine all the edges and their weights using as few queries as possible.

SCORING
-------
You can receive full score (100 points) if the number of your queries is less than 5n.

INTERACTION PROTOCOL
--------------------
Each test case contains multiple sets of test data.

1. First, read an integer T (1 ≤ T ≤ 10^4) indicating the number of data sets.

2. For each set of test data:
   - First read an integer n (1 ≤ n ≤ 10^5)
   - To make a query, output a line "? u v" (1 ≤ u, v ≤ n, u ≠ v)
   - Then read the distance result from standard input
   - To provide your answer, output "! u_1 v_1 w_1 u_2 v_2 w_2 ... u_(n-1) v_(n-1) w_(n-1)"
   - You can output these edges in any order
   - The output of the answer will not count towards the query limit
   - After outputting the answer, immediately read the next set of test data or terminate

After outputting a query, do not forget to output a newline character and flush the output stream. To do this:
  - C++: fflush(stdout) or cout.flush()
  - Java: System.out.flush()
  - Pascal: flush(output)
  - Python: stdout.flush()

CONSTRAINTS
-----------
  - 1 ≤ K ≤ 10^4
  - Sum of all n in the test data does not exceed 10^5
  - The interaction library is non-adaptive (tree structure and edge weights are determined before interaction)

EXAMPLE
-------
Input:
2
3

3

4

7

4

3

7

2

4

5

9

Output:

? 1 2

? 2 3

? 1 3

! 1 2 3 2 3 4

? 1 2

? 2 3

? 2 4

? 1 3

? 1 4

? 3 4

! 1 2 3 1 3 4 2 4 2
