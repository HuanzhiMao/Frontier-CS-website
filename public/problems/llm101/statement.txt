CIRCUIT DISCOVERY
=================

INTERACTIVE PROBLEM

PROBLEM DESCRIPTION
-------------------
You are given a circuit board consisting of N component slots and external switches. Each slot contains either an AND gate (&) or an OR gate (|). The actual type of each slot is hidden.

Your task is to determine the true type of every slot by interacting with the judge.

CIRCUIT SPECIFICATIONS
----------------------
The board consists of:
  - 2N+1 switches numbered 0..2N, each with an ON/OFF state, outputting 0 or 1
  - N component slots numbered 0..(N-1), each outputting 0 or 1

Outputs are determined from the highest index down to 0:

For switches j = 2N, 2N-1, ..., N:
  • If switch j is OFF, it outputs 0
  • If switch j is ON, it outputs 1

For switches j = N-1, N-2, ..., 0:
  • Let the output of slot j be x
  • If switch j is OFF, it outputs x
  • If switch j is ON, it outputs 1-x

For slots i = N-1, N-2, ..., 0:
  • Slot i is connected to two switches U_i, V_i (i < U_i < V_i ≤ 2N)
  • If slot i is AND, it outputs min(output(U_i), output(V_i))
  • If slot i is OR, it outputs max(output(U_i), output(V_i))

Additional properties:
  • For each j = 1..2N, exactly one slot i satisfies U_i=j or V_i=j
  • The output of the circuit is defined as the output of switch 0

INTERACTION PROTOCOL
--------------------
1. The judge first prints N and R, followed by N lines each containing U_i V_i (the wiring of the board)

2. Query:
   Print a line "? s" where s is a binary string of length 2N+1
   Each character sets the ON/OFF state of the corresponding switch
   The judge replies with 0 or 1, the output of the circuit (switch 0)

3. Answer:
   When you have determined the types of all slots, print "! t"
   where t is a string of length N, each character being & or |
   If your guess is completely correct, the judge accepts; otherwise, Wrong Answer

CONSTRAINTS
-----------
  - 1 ≤ N ≤ 8000
  - 1 ≤ R ≤ min(N, 120)
  - i < U_i < V_i ≤ 2N for all 0 ≤ i < N
  - For each j=1..2N, exactly one i satisfies U_i=j or V_i=j
  - At most 5000 queries may be made

SPECIAL REQUIREMENT
-------------------
Your program must be written in C++.

SCORING
-------
  - If queries ≤ 900: full score (100 points)
  - If queries ≥ 5000: 0 points
  - Otherwise: Score = (5000 - queries) / (5000 - 900) × 100

SAMPLE INTERACTION
------------------
Suppose the hidden circuit is "&&|"

Judge outputs:
3 2
3 4
2 4
0 1

Interaction:
? 01001
1
? 11111
0
! &&|
