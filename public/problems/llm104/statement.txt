ATTENDANCE CHECK
================

Time Limit: 2 seconds
Memory Limit: 256 MB

INTERACTIVE PROBLEM

PROBLEM DESCRIPTION
-------------------
There are n students with roll numbers 1 to n. Mr. 1048576 knows that exactly 1 student is absent today. To determine who is absent, he can ask queries to the class.

In each query, he provides two integers l and r (1 ≤ l ≤ r ≤ n) and all students whose roll numbers are between l and r (inclusive) are expected to raise their hands.

However, the students are dishonest. Some students whose roll numbers lie in the given range may not raise their hands, while some students whose roll numbers do not lie in the range may raise their hands.

Only the following 4 cases are possible for a query (l,r):
  1. True Positive: r-l+1 students present and r-l+1 students raised hands
  2. True Negative: r-l students present and r-l students raised hands
  3. False Positive: r-l students present but r-l+1 students raised hands
  4. False Negative: r-l+1 students present but r-l students raised hands

In cases 1-2, students are answering honestly; in cases 3-4, they are answering dishonestly.

The students' strategy always meets these conditions:
  - The students will never answer honestly 3 times in a row
  - The students will never answer dishonestly 3 times in a row

Mr. 1048576 is willing to mark at most 2 students as absent (though he knows only one is). The attendance is successful if the actually absent student is among those two.

CONSTRAINTS
-----------
  - He can only ask up to 2×⌈log_{1.116}(n)⌉ queries
  - 5 ≤ n ≤ 10^5
  - Sum of n over all test cases does not exceed 10^5

SCORING
-------
Your score is inversely linear related to the max number of queries.

INTERACTION PROTOCOL
--------------------
1. First read a line containing integer t (1 ≤ t ≤ 2048): number of test cases

2. For each test case:
   - Read integer n (5 ≤ n ≤ 10^5)
   - To ask a query: print "? l r" (1 ≤ l ≤ r ≤ n)
   - Then read integer x (r-l ≤ x ≤ r-l+1): number of students who raised hands
   - To mark a student as absent: print "! a" (1 ≤ a ≤ n)
   - Then read integer y ∈ {0,1}: if y=1, student a was absent; otherwise y=0
   - This operation does not count as a query but can be done at most 2 times
   - To end a test case: print "#"

3. To flush the buffer: use fflush(stdout) or cout.flush()
